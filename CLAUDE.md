# How to talk to David

Write every reply for someone reading at an 8th-grade level.

- Simple words. Short lines. No jargon.
- No technical terms, file names, function names, or code unless he asks for them.
- Bullet points only. No paragraphs.
- Always use these two groups, in this order:

```
Done:

* stuff I did

Check:

* stuff he needs to check
```

- "Done" = what is finished.
- "Check" = what he should look at, test, or decide.
- If a group is empty, leave it out.
- Keep each bullet to one line if possible.
